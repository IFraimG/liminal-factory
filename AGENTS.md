# Repository publishing workflow

User instructions for every GitHub change:
- Create a separate `codex/...` branch before making changes.
- Open a pull request and merge it into `main`; do not push changes directly to `main`.
- Preserve the feature branch locally and on GitHub after merging.
- Publish an annotated tag and a GitHub Release for each delivery.
- Include the complete final user-facing report in the tag annotation and release description, including validation and material limitations.
